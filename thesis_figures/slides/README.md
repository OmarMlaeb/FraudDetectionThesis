# Thesis figures

Generated by `make_thesis_figures.py`; no models are trained or original results changed.

Use PDF for LaTeX/vector quality, or PNG (300 dpi) for Word. `figures.tex` has ready-to-use figures and captions.

## Reproduce

From the project root:

```powershell
python make_thesis_figures.py
```

This project's existing portable Python also works:

```powershell
.\analysis\supervisor_2026-10-13\runtime\python310\python.exe .\make_thesis_figures.py
```

Dependencies: `numpy pandas matplotlib scikit-learn` (listed in the project requirements).

## Data and interpretation

The figures use the 240 verified reference runs in `analysis/supervisor_2026-10-13/selected_per_seed_results.csv`. They do not mix these with later committee experiments, partial runs or older duplicates. Main-model comparisons use the IEEE-CIS main graph and Elliptic native graph. All groups have ten seeds, 42–51. Error bars are sample SD, not standard error or confidence intervals. The project calls average precision PR-AUC; these figures follow that definition, not trapezoidal area. PR curves default to ten-seed means and sample-SD bands on 1001 recall points; AP legends summarize saved per-run AP. Use `--seed 51` for single-run mode. Use `--preset slides` for one 16:9 panel per file in the slides subfolder. The thesis preset preserves exactly 6.3-inch width with 8-pt base and 7-pt minimum text. Exact checkpoints, hashes, saved/recomputed AP and differences are recorded in `pr_curve_sources.csv`. Predictions are checked against audit SHA-256 hashes, labels/IDs and recorded average precision. The graph construction figure is explicitly synthetic. No model performance is simulated.

The pipeline describes the historical experiments, including their validation selection rules. The August IEEE-CIS Transformer used validation F1 with a 20% alert-rate constraint; see `analysis/supervisor_2026-10-13/SEQUENCE_INPUTS.md` for details.

`plotted_summary.csv` contains the numeric means/SDs/counts; `plotted_per_seed_results.csv` contains the selected source rows. `provenance.json` records input hashes and PR sources. The two illustrative CSVs document the toy graph. `construction_holm_checks.csv` includes all 180 construction comparisons (30 per metric); none survives Holm correction at alpha=0.05. Visual differences are descriptive and non-significance does not establish equivalence.

### 04_pr_curves_ieee-cis

IEEE-CIS; GNNs on the main graph. Mean precision curve and ±1 sample-SD band across seeds 42–51, interpolated on 1001 common recall points. The synthetic (recall=0, precision=1) endpoint is removed first; at duplicate recall levels the first reversed point is retained, with constant endpoint extrapolation. Bands are clipped to [0,1]. Legend AP is the mean ± sample SD of the saved per-run AP scores, matching the ten-seed result tables; it is not the integrated mean curve. Each curve uses its validation-selected checkpoint; checkpoint paths and hashes appear in pr_curve_sources.csv.
